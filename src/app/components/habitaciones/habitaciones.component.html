Acerca de nosotros

Hotel El Buen Rollo, abierto desde 1998, es un hotel familiar dedicado a brindar el mejor servicio a nuestros huéspedes. Con un equipo de profesionales apasionados por ofrecer experiencias únicas, ofrecemos habitaciones modernas, espacios cómodos y una variedad de servicios diseñados para el máximo confort.

Equipo de Desarrollo

Juan Carlos Uriarte Padilla - Estudiante de Ingenieria en Sistemas que no le gusta Angular

Juan Carlos Uriarte Padilla, el responsable del diseño y desarrollo frontend de este sistema de hotel, utilizando Angular, HTML, CSS y JavaScript para crear una interfaz de usuario intuitiva y dinámica. Una gran pasión por la tecnología, buscando siempre la mejora continua, Juan Carlos fue puesto a prueba con este proyecto porque definitivamente no se me da angular ni me gusta el desarollo web, pero hecha con mucho corazon <3.
